
# PRD: Rust Korea Hub (rustkorea.kr)

## 1. 제품 비전 및 전략
- **비전**: "한국어 Rust 생태계의 단일 진실 공급원(Single Source of Truth)"
- **미션**: Topcoat 풀스택 프레임워크를 기반으로, 입문자의 진입 장벽을 낮추고 실무자의 생산성을 극대화하는 커뮤니티 허브 제공.
- **차별화 포인트**: 
  1. 단순 번역이 아닌, AI(Vibe Coding)와 결합한 **실전 컨텍스트 기반 매뉴얼**.
  2. Topcoat의 `#[shard]`를 활용한 **새로고침 없는 실시간 커뮤니티 및 영상 동기화**.

## 3. 핵심 기능 명세 (Epic → Story → Acceptance Criteria)
### Epic 1: 지능형 매뉴얼 시스템
- **Story 1.1**: 사용자는 카테고리(Axum, Topcoat, Tauri)별 시리즈를 탐색할 수 있다.
  - *AC*: 시리즈 목록 페이지에서 썸네일, 난이도(초급/중급/고급), 예상 소요 시간이 표시되어야 한다.
- **Story 1.2**: 사용자는 챕터 읽기 진행률이 자동 저장된다.
  - *AC*: 로그인 사용자는 DB에, 비로그인 사용자는 `localStorage`에 마지막 읽은 챕터와 스크롤 위치(%)가 저장되어 복귀 시 복원되어야 한다.

### Epic 2: YouTube 실시간 연동 허브
- **Story 2.1**: 지정된 YouTube 채널의 새 영상이 15분 이내에 허브에 반영된다.
  - *AC*: 백그라운드 워커가 RSS를 폴링하여 새 영상 메타데이터(제목, 썸네일, 설명, 태그)를 DB에 Upsert하고, 프론트엔드 `#[shard]` 컴포넌트가 자동으로 갱신되어야 한다.

## 4. 성공 지표 (KPI)
- **North Star Metric**: 월간 매뉴얼 챕터 완독 수 (Target: 월 5,000회)
- **보조 지표**: 
  - YouTube 영상 클릭 전환율 (CTR) > 8%
  - 첫 번째 의미 있는 페인트(FCP) < 1.2초 (Topcoat SSR 최적화)
  - 월간 활성 기여자(글 작성/리뷰) > 50명

## 5. 릴리즈 로드맵 (Phased Rollout)
- **Phase 1 (Alpha, 4주)**: Topcoat 스캐폴딩, 매뉴얼 1호(Axum 입문) 5챕터 배포, 정적 YouTube 임베드.
- **Phase 2 (Beta, 8주)**: GitHub OAuth, `#[shard]` 기반 실시간 댓글/검색, 매뉴얼 진행률 추적.
- **Phase 3 (GA, 12주)**: Meilisearch 통합, 라이브 스트리밍 일정 관리, SEO 최적화 완료 및 공식 런칭.
